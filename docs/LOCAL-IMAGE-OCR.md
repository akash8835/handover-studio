# Local printed image OCR
Experimental English/Hindi PNG/JPEG text extraction and editable reviewed text download only. No saved recording change, PDF OCR, handwriting, general visual understanding or guaranteed accuracy. A clean synthetic bilingual sample is not a broad benchmark.
Image input is bounded to 5 MB, 20..4000 pixels/side and 8 MP. Header dimensions are checked before decoding and decoded dimensions rechecked. A separate browser worker handles recognition; cancellation, 60-second engine timeout, late initialization cleanup, navigation cancellation and latest-run guards prevent stale writes. No image bytes go to OCR services or application storage. Model files use the site's origin, without model IndexedDB cache. Downloads require explicit review; edits invalidate that review.
Vendored Tesseract.js 6.0.1/core 6.1.2 and tessdata_fast models are pinned in public/ocr/manifest.json. All four recommended core variants retained. Apache/MIT/BSD notices bundled. Models independently downloaded at pinned commit and SHA-256 matched. No Meta license or paid provider is used.
Assets total about 22 MB, largest below 5 MB, below Cloudflare's 25 MiB/file limit and 20,000 Free file count. Existing run_worker_first remains unchanged, so engine/model requests still count toward Worker request quota and can fail with 429. No paid upgrade or unlimited-capacity claim.
Sources: https://github.com/naptha/tesseract.js/blob/HEAD/docs/local-installation.md ; https://github.com/naptha/tesseract.js/blob/master/LICENSE.md ; https://github.com/tesseract-ocr/tessdata_fast ; https://developers.cloudflare.com/workers/platform/limits/ ; https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/

Additional acceptance: JPEG extraction passes, 3000x3000 (9 MP) rejected, cold import cancel/file switch/navigation guards passed locally and live. A deliberately blurred, low-contrast synthetic image produced wrong text at engine confidence 46 versus clean sample 95. This is evidence of quality risk, not an OCR quality benchmark. Low confidence (<60) now carries an extra explicit major-errors warning, still requires review.
